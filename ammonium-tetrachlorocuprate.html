一、背景化学知识

1.1 铜(II)-氯配合物家族

铜(II)离子与氯离子能形成一系列具有鲜艳色彩的配合物。以下是常见成员：

四氯合铜酸盐 [CuCl4]2-（橙黄色）

将氯化铜的酸溶液与季铵盐盐酸的醇溶液混合，可沉淀出橙黄色的四氯合铜酸盐。该配离子为平面四边形结构，极易被水破坏。

CuCl2 + 2NR4Cl ──→ (NR4)2[CuCl4]↓

二桥-氯二(二氯合铜)酸盐 [μ2-Cl(CuCl2)2]2-（砖红色）

将氯化铜的乙醇溶液与氯化钾的乙酸溶液混合，可沉淀出砖红色的双核平面配位配合物（此外也有三核或多核形式）。

2CuCl2 + 2KCl ──→ K2[μ2-Cl(CuCl2)2]↓

目标配合物：二水四氯合铜酸铵 [Cu(H2O)2Cl4]2-（蓝绿色）

铜离子与四个氯离子在平面形成四配位，轴向上下各与一个水分子配位，构成六配位畸变八面体。

1.2 目标化合物属性

中文名 / 英文名
二水四氯合铜酸铵
Ammonium tetrachlorocuprate dihydrate
化学式
(NH4)2[Cu(H2O)2Cl4] — 两个水分子参与配位，反式构型
分子量与CAS
分子量 277.47，CAS号 10060-13-6
晶体外观
蓝绿色固体，干燥后呈鲜艳的蓝绿色

1.3 结构特点

配位类型
六配位配合物。铜离子与四个氯离子在平面形成四配位，轴向上下各与一个水分子配位
姜-泰勒效应
受 Jahn-Teller 效应影响，两个 Cu—O 键被拉长，形成畸变八面体 [Cu(H2O)2Cl4]2-
配阴离子
[Cu(H2O)2Cl4]2- 为配阴离子，两个 NH4+ 平衡电荷

二、实验制备

2.1 原料准备与安全提示

原料试剂
二水合氯化铜 CuCl2·2H2O — 0.1 mol（约 17.05 g）
氯化铵 NH4Cl — 0.2 mol（约 10.69 g）
无水乙醇（仅用于洗涤）
蒸馏水 约 50 mL
碎冰渣（用于冰水浴）
安全危险提示
二水合氯化铜具有毒性和腐蚀性，使用时请注意安全
无水乙醇具有挥发性和易燃性，需注意防火安全
试剂替代：关键提示
该配合物的铵根阳离子可以用钾离子代替——使用 KCl 同样可以得到对应的二水四氯合铜酸钾盐，0.2 mol 需 14.91 g
但不可用氯化钠 (NaCl) 代替。因为钠离子半径较小，难以形成该配位流派的稳定晶体结构，容易析出复杂的混合物

2.2 实验操作流程

1. 称量药品
准备电子天平，精确称取约 17.05 g 二水合氯化铜（0.1 mol）和 10.69 g 氯化铵（0.2 mol）于烧杯中。
2. 溶解混合
用量筒量取约 50 mL 蒸馏水注入烧杯内，并投入一个磁力搅拌子。
3. 加热搅拌
将烧杯放置在磁力搅拌器上，开启加热搅拌功能，持续搅拌约 15 分钟。
4. 冷却结晶
关闭磁搅并取下烧杯。准备一个装有碎冰渣的结晶皿，将烧杯放入冰水中进行冰水浴冷却。
5. 抽滤洗涤
冷却结晶结束后进行真空抽滤，随后用无水乙醇洗涤晶体数次。
6. 干燥收集
将滤饼移入干燥的培养皿中，用镊子夹出磁搅拌子。最后将产物放入干燥器中等待完全干燥。

2.3 化学方程式

溶液中配位平衡方程

[Cu(H2O)2Cl2] + (x-2)H2O + (2-x)Cl- ⇌ [Cu(H2O)xCl4-x]x-2
(x = 0 ~ 4)

溶液中存在多种铜-水-氯配离子的动态平衡。加热搅拌促进了各配离子之间的相互转化。

冷却结晶析出方程

[Cu(H2O)xCl4-x]x-2 + xCl- + 2NH4+ + (2-x)H2O
→ (NH4)2[Cu(H2O)2Cl4]↓
(x = 0 ~ 4)

冷却降温使平衡向析出方向移动，最终产物为稳定的六配位 trans 构型。

改进方法

2.5 大颗粒单晶培养

该物质可以通过特定晶体生长方法来制备出非常大颗且清澈透亮的浅蓝色单晶，极具观赏价值。

一般养晶原则：
- 用已制得的碎晶重新配制不饱和水溶液，过滤后静置蒸发
- 使用晶种悬挂法使晶体各面均匀生长
- 控制温度稳定在20-25℃，避免震动
- 成品用透明指甲油涂抹表面或环氧树脂封装保存
详细操作参考晶体保存篇

三、安全与注意事项

3.1 危险性

  • 铜毒性：二水合氯化铜具有毒性和腐蚀性。误食含铜化合物会引起恶心、呕吐、腹痛，严重时可导致肝损伤
  • 皮肤刺激：氯化铜接触可能引起皮肤刺激和过敏反应
  • 眼部危害：接触眼睛会导致严重刺激，需立即用清水冲洗并就医
  • 环境危害：铜离子对水生生物有毒，废液不可直接倒入下水道或自然环境
  • 乙醇易燃：洗涤用无水乙醇具有挥发性和易燃性，远离火源

3.2 防护与应急

  • 操作时务必佩戴丁腈手套和护目镜，穿实验服
  • 涉及加热和搅拌操作时注意烧杯固定，防止倾倒
  • 冰水浴降温时注意烧杯温差应力，避免玻璃器皿炸裂
  • 废液处理：加入过量碳酸钠使铜离子沉淀为碳酸铜，过滤后固体按重金属废物处理
  • 急救：误触眼睛立即用大量清水冲洗至少15分钟并就医；误食立即漱口并就医，不可催吐

3.3 禁止事项

  • 禁止在无防护条件下直接接触原料或溶液
  • 禁止将废液直接倒入下水道
  • 禁止用氯化钠替代氯化铵/氯化钾（会得到复杂混合物而非目标晶体）
  • 禁止让未成年人独立操作
  • 禁止在食物附近进行操作或存放

四、成果展示与质量评估

优质晶体特征

优质晶体：
  • 颜色均匀，呈鲜艳的蓝绿色
  • 晶粒完整，表面光滑无裂纹
  • 干燥后色泽保持稳定
  • 无明显杂质夹杂
问题晶体：
  • 晶体发白或颜色暗淡 - 干燥不彻底或杂质过多
  • 晶体过小呈粉末状 - 冷却速度过快
  • 晶体粘连成块 - 过滤前未充分散开
  • 颜色偏黄或偏褐 - 原料纯度不足或有铁杂质

五、问题诊断与解决

常见问题排查

问题一：冷却后不出晶或出晶过少

  • 可能原因：溶液浓度过低（水量偏多）、冷却温度不够低、溶液未充分加热溶解
  • 解决方案：将溶液适当加热浓缩减少水量后重新冷却；或从开始就减少蒸馏水用量；确保冰水浴温度足够低

问题二：溶液加热后仍浑浊，固体未完全溶解

  • 可能原因：水量不足、加热时间不够、搅拌不充分
  • 解决方案：补加少量蒸馏水（每次5 mL），继续加热搅拌至完全澄清

问题三：晶体颜色偏暗或发灰

  • 可能原因：原料含铁等金属杂质、容器不洁净、用 NaCl 替代了 NH4Cl
  • 解决方案：换用分析纯级别原料，清洁所有器材，确保使用 NH4Cl 或 KCl

问题四：抽滤后晶体在干燥过程中潮解

  • 可能原因：空气中湿度大、乙醇洗涤不充分、未及时放入干燥器
  • 解决方案：增加乙醇洗涤次数，抽滤时尽量抽干，立即转移至干燥器；可在干燥器中放入变色硅胶

六、科学原理

6.1 配位化学

溶液中配位动态平衡
在氯化铜-氯化铵水溶液中，Cu2+ 同时与 H2O 和 Cl- 配位，形成 [Cu(H2O)xCl4-x]x-2 (x = 0~4) 系列配离子。各配离子之间处于动态平衡，溶液整体呈墨绿色。
温度对平衡的影响
加热促进离子迁移和各配离子间的相互转化。冰水浴冷却后，平衡向生成稳定产物方向移动，二水四氯合铜酸铵以 trans 构型结晶析出。
阳离子选择性
NH4+ 和 K+ 离子半径适中，能与 [Cu(H2O)2Cl4]2- 配阴离子形成稳定晶格。Na+ 半径偏小，晶格匹配不佳，无法形成稳定晶体。

6.2 颜色成因与姜-泰勒效应

蓝绿色的来源
Cu(II) (d9) 在畸变八面体配位场中，d-d 电子跃迁吸收红光波段（~600-800 nm），透过/反射蓝绿光，因此晶体呈蓝绿色。
姜-泰勒效应
Cu(II) 的 d9 电子构型在简并基态下不稳定，系统通过拉长轴向 Cu—O 键来消除简并，降低能量。这导致四个 Cu—Cl 键（赤道位）较短，两个 Cu—O 键（轴向位）较长，形成畸变八面体。

6.3 结晶条件分析

降温结晶的驱动力
该化合物在水中的溶解度随温度降低而显著下降。冰水浴提供快速降温环境，使溶液迅速达到过饱和状态，产物大量析出。
产率与浓度的关系
产率偏低（42.3%）的直接原因是 50 mL 水量偏多，冷却后仍有大量产物溶解在母液中。减少水量或先加热浓缩均可有效提高产率。

6.4 热致变色现象

什么是热致变色
四氯合铜酸盐系列化合物存在一个非常经典的性质——热致变色（thermochromism）。将干燥后的蓝绿色晶体加热，颜色会从蓝绿色逐步变为黄绿色，最终变为橙黄色；冷却后又恢复蓝绿色。这一可逆过程是配位化学教学中最经典的演示实验之一，最早由 J. Chem. Educ.（1989）系统报道。
变色的化学本质
加热导致晶体失去两个轴向配位水分子，[Cu(H2O)2Cl4]2-（六配位畸变八面体，蓝绿色）转变为 [CuCl4]2-（四配位平面四边形，橙黄色）。这是一个配位数变化伴随的 d-d 跃迁能级变化过程——配体场对称性从 D4h（拉长八面体）变为 D4h（平面四边形），轨道分裂模式改变，吸收波长大幅红移。
热致变色方程

(NH4)2[Cu(H2O)2Cl4] ──→ (NH4)2[CuCl4] + 2H2O↑

蓝绿色（六配位） → 橙黄色（四配位） | 冷却后加水汽即复原

演示操作与注意事项
取少量干燥晶体置于表面皿上，用电吹风或酒精灯微火均匀加热。颜色变化在 50–70℃ 时即开始明显。冷却时，空气中水汽即可使晶体重新水合恢复蓝绿色，但完全复原需要数分钟。注意不要过热（>110℃），否则可能导致不可逆分解。

6.5 晶体学数据

空间群与晶系
四方晶系（Tetragonal），空间群 P42/mnm（No. 136），Pearson 符号 tP18，Z = 2。晶体具有中心对称性，[Cu(H2O)2Cl4]2- 配阴离子和 NH4+ 沿 c 轴交替排列。
晶胞参数
a = b = 7.577 Å
c = 7.946 Å
α = β = γ = 90°
晶胞体积 V ≈ 456.3 Å3
键长（姜-泰勒直观数据）
Cu—Cl（赤道位）：2.29 Å（×4，较短）
Cu—O（轴向位）：2.76 Å（×2，显著拉长）
轴向键比赤道键长约 21%，是姜-泰勒效应的直接证据。NH4+ 与 [Cu(H2O)2Cl4]2- 之间通过 N—H···Cl 氢键形成三维超分子网络。
密度
计算密度约 2.02 g/cm3，属于中等密度的离子型配位晶体。

七、应用领域

配位化学教学
作为 Cu(II) 六配位畸变八面体的经典案例，直观展示姜-泰勒效应的结构后果，是配位化学教学中常用的模型化合物
无机合成
作为其他铜配合物的合成前体或中间体，在无机化学研究中具有一定应用价值
热致变色演示
加热脱水后颜色从蓝绿色可逆变为橙黄色，是配位化学教学中最具视觉冲击力的热致变色演示实验之一（J. Chem. Educ. 1989 经典实验），适合课堂演示或科普展示
晶体收藏
其鲜艳的蓝绿色和可通过慢速结晶获得的大颗粒单晶形态，使其在化学爱好者群体中具有较高的收藏和展示价值
